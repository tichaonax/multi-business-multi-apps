It is based on broad industry groupings used in standard business classifications, adapted for practical small-business onboarding and search suggestions. [bea](https://www.bea.gov/naics2022)

## UI rules

- Show at most **five suggestions** at once, as in the provided UI.
- Display the parent domain in smaller muted text and the service category in the main line.
- Keep emojis on both the domain and the suggested category.
- Rank exact phrase matches first, then aliases, prefixes, related keywords, and fuzzy matches.
- Let users choose a suggestion, browse all domains, or create a custom category if no relevant suggestion is found.
- Store a canonical category ID internally; show editable labels only in the user interface.
- If a user selects an overly broad category such as `🍽️ Food Vendor`, optionally ask one next question to refine it, such as: “Do you sell cooked meals, snacks, drinks, or fresh produce?”
